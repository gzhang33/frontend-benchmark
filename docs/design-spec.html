Benchmark UI Redesign

重新思考
模型评测体验

将当前三栏拥挤布局重构为 Figma 风格的工作台。对比区域最大化，评分面板从右侧抽屉按需唤出，批量操作流程化，视觉品质全面升级。

核心原则

对比优先 — 主区域 100% 用于模型输出对比，所有辅助功能（评分、详情、配置）通过抽屉/弹出层按需访问，不占用常驻空间。

操作流简化

新建会话 → 选模型 → 选用例 → 一键生成 → 评分 → 下一个。消除当前需要手动切换多个面板的痛点。

01 对比区最大化

移除常驻 info-panel，评分通过右侧可折叠抽屉访问。对比区从 ~40% 提升到 ~75% 可视面积。

02 批量流程化

勾选用例 → 一键批量运行 → 逐个评分 → 自动跳转下一个。进度清晰，不再需要手动切换。

03 视觉升级

精致暗色调，更好的层次感，微交互动效，专业数据可视化。告别平庸的深蓝配色。
